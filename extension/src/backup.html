Learning backup

Keep your old unpacked installation and its profile intact. Update that installation to a version with this page, export there, then open this page in the separate new installation. Do not remove the old one until you have checked your restored review queue.

Export from this installation

Download supported learning progress, personal entries, generated packs and learning preferences. Export only reads local state.

An unverified card from an old or removed language pack blocks the whole backup. The old installation and its history stay intact; this tool cannot safely include that card or import part of the history.

Import into a fresh learning profile

Choose a backup file from your computer. Import is available only when this installation has no meaningful learning progress and no Gemini key. Initialized defaults are okay. Existing progress, generated packs or an unknown storage format are conflicts; this page cannot merge or replace them.

Check before importing

Excluded: Gemini keys, model/cache/quota data, site choices and host permissions, page text and URLs, pending captures, introduction reservations, reveal and inline tickets. Import never grants a host, enables a site, or calls Gemini. Re-enter a key and choose sites separately afterward.
