2. Choose where it may read

When Lang Weave is on for a site, it sends readable text from that site's pages to Google's Gemini API with your own key. Gemini uses that context to choose words in the reading language you select in Settings. Forms, editable text and code blocks are skipped. Lang Weave has no account or telemetry.

Google may use requests made with a free key to improve its products, and human reviewers may see them. A billed key avoids that use. Provider quotas and charges can still apply.

The Gemini API requires users to be 18 or older.

Page text is not sent until you add a key, choose a site policy here, and Chrome allows access to a site. Testing a key in Settings sends a short test prompt to Gemini. Generating a vocabulary pack in Settings sends a separate request to Gemini. Sensitive sites such as webmail, banking, health and AI chat start off under either choice. You can change sites later in Settings.

Read on X? You can allow x.com explicitly.

3. Add a key and start learning

Try Spanish placement (optional)

Open Settings to get a Gemini key, save it, and test it. The key stays in extension storage and is sent to Google with model requests.

Reading level controls which bundled words can appear; Beginner is a good start.

Gradual learning is on for new installs, at 5 new words a day. It introduces words from your reading and schedules short reviews. Settings shows whether it is on for you, changes the pace or turns it off.
